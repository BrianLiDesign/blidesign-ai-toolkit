# Domain documentation

This repository uses the single-context layout:

- Read `CONTEXT.md` before changing marketplace concepts or naming.
- Record hard-to-reverse architecture choices in `docs/adr/`.
- Keep public identifiers stable after a release; use display names for cosmetic changes.
- Update `CONTEXT.md` when a new durable domain term is introduced.
- Skills are the portable unit; Codex `.codex-plugin/` packaging is an adapter, not the content model.
